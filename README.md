# Team 13 - Cloud Photo Gallery Application

This repository contains the code and documentation for our cloud-based photo gallery, leveraging Google Cloud Platform (GCP) services.

## Architecture Components

1. **Google Cloud SQL:** MySQL relational database instance storing user credentials and photo metadata.
2. **Web Application Framework:** Backend API built to handle requests, user authentication, and file routing.
3. **Google Compute Engine (GCE):** Scalable virtual machine hosting the deployed application.

## Repository Structure

- `/backend` - Server code, API routes, and database connection logic.
- `/frontend` - User interface (HTML/CSS/JS or framework), layouts, and client-side logic.
- `/database` - SQL schema definitions and database setup scripts.
